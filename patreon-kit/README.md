# DoinkTV Patreon Kit

Use this folder as a quick creator-page refresh kit for the DoinkWizard Patreon.

## Visual Assets

- `assets/doinktv-patreon-cover.png` - Patreon cover/header, 2500 x 1000.
- `assets/doinktv-patreon-avatar.png` - square profile image, 1024 x 1024.
- `assets/doinktv-patreon-post-card.png` - reusable post image, 1600 x 900.

The cover keeps the key visual weight toward the right side and keeps text minimal so it survives Patreon cropping on desktop and mobile.

## Brand Direction

- Dark CRT glass, scanlines, and slightly unstable broadcast texture.
- Teal and warm-gold accents pulled from the site.
- Small labels that feel like channel bugs, station IDs, schedule cards, and old TV UI.
- Copy should sound inviting, strange, and specific rather than polished to death.

## Suggested Page Setup

- Page name: `DoinkWizard` or `DoinkTV by DoinkWizard`
- Short tagline: `A weird little internet TV station, kept alive by viewers.`
- Brand color: try `#68c3b7` first, then `#f0b84b` if Patreon needs more contrast.
- Cover: upload `doinktv-patreon-cover.png`.
- Profile image: upload `doinktv-patreon-avatar.png`.
